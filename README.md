# pair-wise-yy-59 法律文件披露、去密与发布质控工作台

用于诉讼披露批次中的区域去密、原页/发布页双人复核、文档标签和发布门禁。PDF.js 真实渲染示例文档，去密区域可绘制、确认并持久化到本地草稿。

## 冻结批次与发布门禁

质检与导出只认真正冻结过的快照，而不是随时变动的草稿：

- **冻结**：批次页选择文档后冻结，定格每份文档当时的密级、已确认去密区域与复核项；草稿区域不入快照。
- **失效联动**：冻结后任一文档再保存（密级 / 去密区域变化、版本递增）都会让引用它的批次立即变为「已失效」，批次页与质检页的导出入口随即关闭。旧批次不删除，仍可查看快照与校验结论。
- **复核后重建**：完成双人复核后再冻结新批次，新批次基于新版本，可正常校验、导出；旧批次保留可查。
- **快照 / 版本校验 / 导出三分开**：冻结只存档；「执行版本校验」逐份比对快照与当前草稿（revision、密级、已确认区域）；「生成发布包」是最后一道闸，必须校验通过且未漂移才放行。审阅与质检操作不受批次影响，照常进行。
- **跨窗口并发**：两个浏览器窗口编辑同一文档时，所有保存都带乐观版本基准；后保存一方若发现另一窗口已先保存，会收到版本冲突提示且本次写入整体不落地，不会覆盖先保存内容，加载最新版本后可重新操作。窗口间通过 `storage` 事件实时同步文档与批次。

## 技术栈

React、Radix UI 风格组件、Zustand、TanStack Router、TanStack Query、PDF.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62059`。示例 PDF 由浏览器端生成后交给 PDF.js 渲染，不需要外部文件。

```bash
npm run build
npm run verify:freeze   # 冻结/失效/导出门禁/跨窗口冲突的端到端校验（44 项）
```
